Privacy Policy / プライバシーポリシー

JARVIS CF (JARVIS Content Factory) — Last updated / 最終更新: 2026-09-30 — Home

1. Who uses this app

JARVIS CF is a personal desktop tool used only by its owner to analyze the owner's own social media accounts. It is not offered to the public.

2. Data we access

  • TikTok (only after the owner authorizes via TikTok Login Kit): basic profile info from user.info.basic (open ID, display name, avatar), and the owner's public video list and metadata from video.list (video ID, title/description, creation time, duration, share URL, and view, like, comment and share counts).
  • YouTube / Instagram: the owner's own post list and post statistics through the official APIs, after the owner's authorization.

We do not access other users' private data, direct messages, contacts, or payment information.

3. How data is used

Only to show the owner how their own posts perform over time and to suggest improvements for future posts (for example which topics or video lengths work better).

4. Storage and security

  • All data is stored locally on the owner's Windows PC (a local SQLite database). There is no server that collects it.
  • Access tokens and app credentials are stored in a local folder outside the project and are never written to logs.
  • Data is not sold, rented, or shared with third parties, and is not used for advertising.

5. Retention and deletion

Data is kept on the owner's PC until the owner deletes it. The owner can revoke access at any time in TikTok (Settings and privacy > Security > Apps and services permissions) and in the Google / Meta account settings, and can delete the local database and token files.

6. Changes and contact

Updates will be posted on this page. Contact: GitHub Issues of this site.
