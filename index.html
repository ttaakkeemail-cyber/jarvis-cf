What it is

JARVIS CF is a Windows desktop tool run by its owner on their own PC. With the owner's explicit authorization, it reads the owner's own public post list and post statistics (for example views, likes, comments and shares) from TikTok, YouTube and Instagram, and stores them locally to compare results and plan better content.

  • It is used only by its owner for their own accounts. It is not offered to other users.
  • TikTok: it uses Login Kit for Desktop and reads data with the user.info.basic and video.list scopes only.
  • It does not post, edit or delete anything on TikTok. Nothing is published without the owner's manual approval.
  • Data is stored only on the owner's PC and is never sold or shared.

概要

JARVIS CF は、運営者本人が自分のPCで使うWindows用の個人ツールです。本人が明示的に許可した場合に限り、TikTok・YouTube・Instagram から本人のアカウントの公開投稿一覧と実績（再生数・いいね・コメント・シェア等）を読み取り、PC内に保存して投稿の改善に使います。

  • 運営者本人のアカウント専用です。他の利用者には提供していません。
  • TikTok では Login Kit（デスクトップ）を使い、user.info.basic と video.list の読み取り権限だけを使用します。
  • TikTok への投稿・編集・削除は行いません。本人の承認なしに外部公開することはありません。
  • データは本人のPC内にのみ保存し、販売・第三者提供はしません。
